Engineered for Content Automation

Combining computer vision, local rendering, and direct social graph APIs into a single desktop application.

🎯

Computer Vision Event Detection

Scans raw gameplay recordings using optical character recognition (OCR) and pixel delta analysis to pinpoint multikills, clutch outplays, and decisive teamfights automatically.

🎥

Smart 9:16 Dynamic Camera

Converts widescreen 16:9 VODs into vertical 9:16 reels by tracking player champions in real-time, applying action zooms, speed-ramping, and seamless looping for maximum retention.

🎵

TikTok Direct Post v2 API

Securely authenticates via PKCE OAuth 2.0 and uploads videos directly to TikTok using chunked file streaming with automated cover frame selection and hashtag injection.

📈

Closed-Loop Learning Engine

Pulls performance data from YouTube Analytics and Meta Graph API to learn which action formats convert highest, continuously tuning pacing parameters.

⚡

Hardware-Accelerated NVENC

Renders 1080x1920 60FPS vertical shorts in under 12 seconds utilizing local GPU hardware encoders with lossless audio normalization.

🔒

Zero-Cloud Data Security

All video footage, rendered files, and OAuth API tokens are stored strictly on the user's local disk. No personal data or video ever passes through third-party servers.

TIKTOK CONTENT POSTING API v2

Direct Post & Creator Integration

Shortsyt Studio connects directly to the official TikTok Developer Platform to allow gaming creators to publish their rendered highlight clips straight to their TikTok profile.

We request only the minimum required OAuth scopes needed for publishing your own video content:

  • video.publish Initiates and publishes video posts on TikTok
  • video.upload Uploads video chunk payloads securely via HTTPS
  • user.info.basic Displays your TikTok profile name & avatar in the dashboard

Security & Compliance Commitment

Shortsyt complies fully with the TikTok Terms of Service and Community Guidelines.

• OAuth tokens are encrypted locally on the user's computer.
• The user can revoke permissions at any time via TikTok Settings > Security > Manage App Permissions.
• No user telemetry, credentials, or tracking cookies are collected.

How Shortsyt Works

From local match recording to viral multi-platform short in 3 steps.

01

Select & Scan Clip

Drop gameplay MP4s recorded by Outplayed, Medal, or OBS. The OCR detector finds kill feeds, champion names, and high-impact timestamps automatically.

02

Render & Polish 9:16

The FFmpeg engine crops to vertical 9:16, applies dynamic camera pans, synchronizes kill drops to music beats, and runs automated QA checks.

03

Publish to TikTok & Socials

Click publish to send the clip to TikTok, YouTube Shorts, Instagram Reels, and Facebook Reels with matching tags, descriptions, and thumbnails.
