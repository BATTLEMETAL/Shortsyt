## 1. Service Description
Shortsyt is a personal automation tool that records highlight moments from League of Legends gameplay, renders short-form video clips, and publishes them to social media platforms (YouTube, TikTok) on behalf of the authenticated account owner.

## 2. Usage
This software is intended for personal, non-commercial use by the account owner. The tool accesses only accounts explicitly authorized by the user via OAuth 2.0.

## 3. Data
